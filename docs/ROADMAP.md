# Aicrew delivery order

The aimem aicrew board owns live status and dependency evidence. This file
sets direction, not another checklist.

1. Verify repository preparation and adopt the reviewed AIForge contract from
   aimem. Establish minimal CI and confirm external-review integration.
2. Freeze aicrew membership/session and cross-service execution contracts,
   consuming the reviewed aimem context and reservation prerequisites.
3. Implement small increments: linked identities and sessions, workspace
   convention, invitations/onboarding, context switching and durable inbox.
4. Complete assignment/review/recovery and real Claude/OpenCode integration.
5. Verify observer tooling and run the bounded one-coordinator/one-worker/
   one-project pilot with real aimem knowledge access.
6. Independent workers and multi-project validation follow the first pilot.
   Web management and ai-skills GitHub hosting remain later work.

Respect the dependency graph and READY checks before claiming. Estimates are
provisional: split larger work before implementation. Repository creation and
local documentation do not imply the architecture or runtime is delivered.
No live workers, product release or deployment without the corresponding
operator-authorized gate. The preparation session reviews/monitors only;
assigned implementation sessions own their respective repositories.
